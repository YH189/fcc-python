# Projects

This folder contains complete, functional Python applications — larger 
in scope than the scripts in the Logics folder, combining multiple 
concepts into a single working program.

Where the Logics folder focuses on isolated problem-solving, this folder 
focuses on applying those fundamentals to build something usable end to 
end.

## What you'll find here

- Self-contained Python applications, each in its own file
- Programs that combine functions, logic, and data handling into a 
  complete workflow
- Where applicable, integration with external data sources or APIs

## Structure

Each project is independent unless otherwise noted. File names indicate 
the purpose of each application.

## Purpose

- Apply core programming logic to real, usable programs
- Practice structuring and organizing larger codebases
- Build a portfolio of complete, working projects
