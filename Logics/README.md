# Logics

This folder contains standalone Python scripts focused on core programming 
logic — control flow, functions, conditionals, and data manipulation.

Each script is written to solve one specific, well-defined problem. The 
goal is to build a strong foundation in problem-solving and algorithmic 
thinking before applying these concepts to larger, multi-part projects.

## What you'll find here

- Small, self-contained scripts (one problem per file)
- Clear, readable code with functional logic
- Practice with Python fundamentals: loops, conditionals, string handling, 
  functions, and basic data structures

## Structure

Each file in this folder is independent and can be run on its own. No file 
depends on another. File names describe the problem being solved.

## Purpose

- Strengthen core logic and problem-solving skills
- Build muscle memory for clean, functional Python
- Serve as a personal reference for common patterns and techniques

This folder will continue to grow as more scripts are added over time.
